# Native GGUF and Settings preview — 7 November 2026

Unsigned Windows x64 prerelease for a personal, non-profit project. Preserve your existing profile and model files before testing.

## Changes

- Shared embedded llama.cpp b11784 native libraries, with CUDA, in a bundled private-pipe worker. No llama-server or HTTP model-inference API is required. The desktop UI still uses its existing local transport.
- Select a compatible local GGUF from setup or Settings. Normal retains separate Fast/Advanced presets and a custom model option. Arbitrary GGUF architectures are not guaranteed supported.
- Failed model loads release the operation gate and restore the previous configuration where possible. Worker failures can recover without leaving the app permanently busy.
- Main Settings stays open on outside clicks; Close, Done and Escape dismiss it. Unchanged status polling no longer repeatedly redraws its model panel.

## Verification and limits

The public portable suite passes 51 tests, including model-switch authorization, failure recovery, recent-model storage and worker cleanup. Local desktop checks covered custom GGUF switching, an invalid-model recovery, preserved history, reopening, and Settings stability. Installer payload integrity was checked locally.

These newly rebuilt installers have NOT received a fresh clean-PC qualification. Older maintainer-reported other-PC tests apply to older builds only. Current testing used an 8GB GPU; this update does not establish new 27B, voice, vision or performance results. Optional image, video, speech, Unity and Adobe integrations require their separate existing dependencies. Model weights are not included. The Chrome extension's legacy HTTP model connection still needs a native bridge.

The independent experimental YOE Engine is not production-qualified. The stable native backend remains embedded llama.cpp, with its original attribution. No speed improvement is claimed.

The attached edition-specific source archives correspond to the packaged applications. This repository provides the updated Normal developer source and portable build tooling; it excludes native runtime binaries and private configuration. Keep all bundled third-party notices.
