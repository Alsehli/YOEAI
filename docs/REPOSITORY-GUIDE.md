# Repository navigation

| Section | Purpose and current scope |
|---|---|
| Code | Source snapshot, notices, setup and release records. Match newer installer binaries to their attached source archives. |
| Issues | Reproducible bugs and evidence-based release gates; templates collect version, steps and redacted diagnostics. |
| Pull requests | Reviewed changes with hosted checks. Empty means no changes are awaiting review. |
| Actions | Windows source validation/build/smoke checks and CodeQL static analysis. Optional runtime and hardware tests are separate. |
| Projects | Public roadmap with Todo, In progress and Done; open work must retain its actual state. |
| Wiki | User-facing installation, features, troubleshooting, privacy and contribution guides. |
| Security and quality | Private reports, code/dependency alerts and security policy. Scanner configuration is not a security certification. |
| Insights | GitHub-generated activity and community metrics; history grows with actual usage and contributions. |
| Settings | Maintainer configuration, not another unfinished product feature. |

See the [roadmap](ROADMAP.md), [Wiki](https://github.com/Alsehli/YOEAI/wiki), [issues](https://github.com/Alsehli/YOEAI/issues) and [actions](https://github.com/Alsehli/YOEAI/actions).
