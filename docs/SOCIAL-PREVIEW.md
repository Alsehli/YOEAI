# Social preview

`images/social-preview.png` is 1280×640 and uses the original YOE fox, Manrope typography and the blue/white project palette. It is a branding composition, not an application screenshot. Rebuild with `python tools/make_banner.py` after installing Pillow.

GitHub's repository social-preview upload is not exposed by this connector. As repository administrator: open https://github.com/Alsehli/YOEAI/settings, find **Social preview**, choose **Edit → Upload an image**, and select this PNG. The README banner is independent and works without this upload. Do not report the Settings preview as uploaded until confirmed.
