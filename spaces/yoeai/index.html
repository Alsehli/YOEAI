Where things run

Chat, PDF/text extraction, image captions and dictation run on your device. Libraries and model weights download from public CDNs and Hugging Face. Images use an external community Space only after you open them. Inputs entered into those tools go to their operators.

What this version can do

Browser chat, real token usage, model load/unload, file excerpts, image descriptions, speech-to-text, device read-aloud, and an embedded community image tool. Image captions are a limited description, not the desktop model’s full vision capability. This web companion cannot control Windows, access arbitrary local folders, or run desktop plugins.

Privacy and limits

No server-side conversation database or paid inference keys. History is in memory unless you enable local browser storage. Clearing chat removes only this app’s stored history. Internet is needed for initial downloads and external creative tools. Browser GPU/memory limits and community quotas may interrupt tasks; errors are shown rather than replaced with pretend results.

Small models can make mistakes. No automatic web research is included; current claims and exact citations need independent verification.
